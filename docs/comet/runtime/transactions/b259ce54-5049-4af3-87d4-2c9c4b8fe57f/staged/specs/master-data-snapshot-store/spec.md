# 主数据快照存储（PostgreSQL）

## 角色

PG 是 SAP 主数据的只读检索投影，不是第二权威源。SAP 属性为导入投影，不允许通过解析 API 改写；本地别名与 SAP 权威字段分开，不覆盖正式描述。

一次用户选中只生成当前会话确认，不自动写公共 alias。应用搜索账号只有必要视图的只读权限；迁移/导入使用独立权限。

## 数据模型

支持 Material、Customer、Supplier 的领域投影，不复制全部 SAP 表。稳定身份 = 来源系统 + client + 对象类型 + 规范编码。

多语言描述多行不视为多个实体。别名按对象关联，含来源、适用范围、有效状态。区分属性按实际需要建模，不建全企业 EAV。

对象与组织范围关系（如物料工厂扩展）与身份分离。记录数据快照、来源提取时间、加载时间、覆盖范围、有效状态。

编码一律字符串：保留前导零、字母数字、小数规格、特殊字符；不做通用补零或整数转换。Supplier/Customer 角色编码不默认等于 BP 号，无依据时保留独立字段。

pg_trgm 扩展仅在隔离测试环境创建；生产安装扩展不在授权内。

## 快照导入

显式本地 CSV/JSON 快照导入器：明确列定义、编码、空值、语言与组织关系格式；批次声明含来源系统/client、来源时间、覆盖范围并经校验。

干跑验证；格式错误或身份重复时不部分发布。staging + 原子发布（或等效事务），读取不见半批数据；失败继续用上一有效快照。

第一版仅支持 full snapshot，对 incremental 明确拒绝。full snapshot 只替换声明覆盖范围，不误删未导入的其他系统/对象。处理失效/删除，避免已消失对象永久保留为有效候选。

导入时间不冒充 SAP 来源更新时间；来源时间未知如实记录 unknown。同一快照重复导入幂等。

合成示例数据覆盖三类对象：重名、多语言、近似规格、不同组织范围、失效对象；严禁使用真实客户数据。

## 本地启动与凭据

提供可复现的本地 PG 启动、迁移、导入、测试说明。不自动安装 Docker、不删卷、不改系统服务。

密码/连接串不出现在聊天、命令参数、代码、日志或提交；示例只写占位符或 credential reference。缺少安全凭据方式时清楚报告阻塞，不自创明文兜底。
